# Debian/Ubuntu (apt): build tools plus the CLI tools the setup expects.
# One package per line; a name this release does not carry is skipped with a warning.
# `name>=version` installs only if apt's candidate is at least that version (Ubuntu
# 26.10 has Neovim 0.12; 26.04 and 24.04 do not). Where it is skipped, or the tool is
# missing from apt altogether (lua-language-server, stylua, golangci-lint, kubectl),
# `install.sh tools` downloads it from its official release. Keep the versions in
# step with NVIM_MIN / TREE_SITTER_MIN in setup/tools.sh.
